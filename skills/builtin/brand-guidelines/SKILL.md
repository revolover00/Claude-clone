# Brand Guidelines & Design System Template

## Overview
This skill provides a structured template for corporate visual identity, styling rules, and design standards.

## Brand Color Palette (Configurable Placeholders)

- **Dark / Foreground**: `[BRAND_DARK_COLOR]` (e.g., `#1e1c1a`)
- **Light / Surface**: `[BRAND_LIGHT_COLOR]` (e.g., `#faf9f5`)
- **Primary Accent**: `[BRAND_PRIMARY_ACCENT]` (e.g., `#d97757`)
- **Secondary Accent**: `[BRAND_SECONDARY_ACCENT]` (e.g., `#4a88c7`)
- **Muted / Borders**: `[BRAND_MUTED_COLOR]` (e.g., `#e5e3dc`)

## Typography

- **Headings**: `[BRAND_HEADING_FONT]` (e.g., Inter, Poppins, Outfit)
- **Body Text**: `[BRAND_BODY_FONT]` (e.g., Lora, Georgia, Source Sans)
- **Monospace / Code**: `[BRAND_CODE_FONT]` (e.g., JetBrains Mono, Fira Code)

## Application Rules

1. Maintain consistent contrast ratios (WCAG AA compliant).
2. Use accent colors purposefully for key actions and active visual anchors.
3. Output artifacts formatted as clean, complete HTML, CSS, SVG, or Markdown.
